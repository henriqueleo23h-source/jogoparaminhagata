# Arquivo Noturno

Jogo de mistério no navegador, com 9 casos reais, 6 fases por caso (o caso, cena do crime, perícia policial, investigação, evidências e solução), perguntas de Sim, Não ou Irrelevante e 3 vidas por caso.

As imagens são ilustrações. Os textos seguem relatos públicos sobre os casos.

## Como rodar

Abra o `index.html` no navegador. É um arquivo único, sem instalação.

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub.
2. Envie o `index.html` e o `README.md` para a raiz do repositório.
3. Vá em Settings, Pages, e em Source escolha "Deploy from a branch".
4. Escolha a branch `main` e a pasta `/ (root)`, e salve.
5. Em alguns minutos o jogo fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
